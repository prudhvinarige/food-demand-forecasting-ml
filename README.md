# Food Demand Forecasting Using Machine Learning

## Overview
This project predicts food demand using machine learning algorithms to help organizations improve inventory planning and reduce food wastage.

## Problem Statement
Manual food demand prediction is often inaccurate and can lead to shortages or excess inventory. This project uses machine learning models to automate demand forecasting.

## Dataset
- 456 records
- Target Variable: num_orders
- Numerical and categorical features
- Missing values handled using mean imputation
- 80% Training Data
- 20% Testing Data

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Voting Regressor

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Results
After performance comparison using MAE, MSE, RMSE, and R² Score, KNN achieved the best prediction accuracy.
